NISARGA PORTFOLIO — HTML + CSS

FILES
- index.html: all page structure and content
- styles.css: the color palette, positioning, typography and responsive rules
- assets/nisarga-cutout.png: the transparent portrait provided by you

TO VIEW
Open index.html in Chrome, Edge, Firefox or Safari. No build step needed.
The page uses Google Fonts. An internet connection is needed to load the exact fonts,
but built-in fallback fonts will work offline.

TO CUSTOMIZE
- Colors: edit CSS variables at the top of styles.css.
- Headline, paragraphs and projects: edit text in index.html.
- Your email: replace hello@example.com in the Contact section.
- Portrait: replace assets/nisarga-cutout.png with your updated cutout.

NOTE

Replace them with live project links when ready.
